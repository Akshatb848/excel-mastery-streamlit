# Excel Mastery for Mac (Streamlit)

A 180-lesson Excel course for working professionals in India who are new to Excel on a Mac, from the first cell to Copilot and Claude in Excel.

This Streamlit app shows the course website full screen and offers the practice workbooks as downloads.

- Course website: https://akshatb848.github.io/excel-mastery-course/
- Direct links: `?lesson=S07-02`, `?lesson=S07` (a section), or `?page=functions|tips|shortcuts|help`

Run locally:

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

To point the app at another copy of the site, set `SITE_URL` in the app's secrets.
